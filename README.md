Welcome to the **Mad Scientist Potion Lab**, an interactive and educational web application designed to teach kids real-world Physics, Chemistry, and Math using everyday kitchen ingredients! 🧑‍🔬🍋

## 🌟 Educational Features

The lab simulates real chemical and physical behaviors in an intuitive, visual way:

- **🌡️ Solubility & Temperature Limits**: Kids learn that adding Sugar (Solute) to Water (Solvent) has limits. They'll visually see undissolved sugar pile up at the bottom of the beaker. To fix it, they must use the stove to heat the liquid and increase its solubility!
- **💧 Density & Separations**: Watch as Cooking Oil floats to the top of Vinegar because it is non-polar and less dense. 
- **🔗 Chemical Emulsifiers**: Learn how to bind separated layers (Oil and Vinegar) together by adding an emulsifier like Mustard!
- **🧮 Math, Ratios & Fractions**: Missions require players to mix liquids in specific proportions (e.g., a 1:4 ratio of Lemon Juice to Water, or adding exactly 1/2 of the total volume).
- **📋 Live Observation Log**: A dynamic log panel explicitly translates the user's actions into scientific observations (e.g., *"Physics: Oil is non-polar and less dense! It's floating."*), reinforcing learning in real-time.

## 🎮 How to Play

1. **Select a Recipe/Mission**: The app guides you through various recipes like "Sweet Lemonade" and "Vinaigrette Dressing".
2. **Mix Ingredients**: Use the `+10` and `+20` unit buttons to add exact amounts of Water, Lemon Juice, Sugar, Vinegar, Oil, and Mustard.
3. **Control the Physics**: Use the **Stove** buttons to heat up or cool down the beaker to trigger specific chemical states.
4. **Win**: Achieve the perfect volume, temperature, and mixture ratios to complete the recipe!

## 🚀 Quick Start (Local Development)

This project is built using modern **React 19** and **Vite** for incredibly fast development.

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/tinouchemassinissa/Mad-Scientist-Lab.git
   cd Mad-Scientist-Lab
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port specified in your terminal).
